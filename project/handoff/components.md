# Component Inventory

## Shell
AppShell, PrimarySidebar (nav item + badge), ContextSidebar, MainWorkspace,
DetailPanel (URL-aware, closable), MobileShell (header + bottom nav), StorageMeter,
CurrentUserFooter (presence, theme shortcut).

## Chat
ConversationRow (avatar+presence, preview, time, unread badge, typing state),
ChatHeader (identity + search/audio/video/info actions), PinnedBanner,
DateSeparator, MessageBubble (in/out, sender+role badge, timestamp, read ticks),
ReplyPreview, AttachmentCard (PDF), ImageMessage, ReactionPills, PollCard
(options + % bars + votes), Composer (attach, emoji, send; Enter-to-send).

## Status
MyStatusCard, StatusRow (ringed avatar: purple=unseen, gray=viewed), ChannelRow,
StatusViewer (segmented progress, auto-advance 5s, tap-to-advance, caption,
reply bar, reaction pills), ViewersDonut (conic-gradient), AudienceCard,
ReactionsSummary, PrivacyCard, ActionsList (mute/share/archive/delete).

## Groups
GroupCategoryRow (+count), GroupCard (icon, privacy badge, members, avatar stack,
last activity, unread), GroupHeader (invite CTA), GroupTabs, AboutCard (+tags),
RecentMediaGrid, PinnedPostCard, EventRow (calendar date block), AnnouncementRow.

## Contacts
ContactCategoryRow, ContactsTable (name/role/dept/status/phone/actions,
ellipsis truncation), ContactProfilePanel (quick actions, about, org, shared
groups/files, notes, tags), Pagination.

## Files
FileCategoryRow, WorkspaceRow, FilesTable (icon, name+star, type, size,
modified, owner, shared-in, status ✓/☁), FileDetailPanel (preview, download/
share, details, sharing + avatar stack, version history, comments + composer).

## Calls
CallStage (dark), VideoTile (speaking ring, mic-off label), CallControlBar
(mute/camera/share/participants/reactions/raise-hand/record/more/end),
ParticipantRow (host/you badges), CallChatPanel (messages/files tabs), PiP self
view, CallTopBar (duration, network quality).

## Settings / Profile / Admin
SettingsNavRow (title+desc), SettingRow (label + control), Toggle, SegmentedControl,
AccentSwatchPicker, WallpaperGrid, RangeSlider, ProfileCoverHeader, InfoCard,
ActivityRow, DeviceRow, SecurityRow, AdminMembersTable (role chips, manage/
suspend), StorageCard, AuditEventRow.
